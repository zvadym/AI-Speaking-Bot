# Bot Configs (`deploy/bots/*.json`)

Each file defines one Telegram bot for a fixed language pair and provides:

- Language pair (`base_language`, `learning_language`)
- Optional display name (`bot_name`) used in generated LLM prompts
- Telegram credentials (n8n credential ID and bot token)
- Localized UI texts used by the `Set Locale` node in the workflow

These config files are mounted into the API container at `/deploy/bots` and read at startup.

## File naming

Use `deploy/bots/<base>-<learning>.json` (example: `deploy/bots/uk-de.json`).

## Schema (informal)

```json
{
  "bot_key": "uk-de",
  "base_language": "uk",
  "learning_language": "de",
  "bot_name": "Леся",
  "telegram_credential_id": "V39Lr6UfHsLcBQsS",
  "telegram_bot_token": "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz",
  "locale": {
    "waiting_text": "...",
    "loader_messages": ["...", "..."],
    "hi_message_text": "={{ ... }}",
    "...": "..."
  }
}
```

Notes:

- `bot_key` should equal `${base_language}-${learning_language}`.
- `bot_name` is optional. If omitted, prompt generation falls back to `bot_key`.
- `telegram_credential_id` is the **n8n credential ID** (used by n8n workflows).
- `telegram_bot_token` is the **Telegram bot token** (used by the API service). **Required**.
- LLM prompt fields (`model_system_prompt`, `model_support_prompt`, `model_hints_prompt`, `model_summary_prompt`) are generated by `scripts/render-n8n-workflows.py` from files in `deploy/prompts/`.
- `locale` should contain non-LLM UI keys used by the `Set Locale` node in the `ai-bot` template.
- `locale.loader_messages` can be either:
  - an array of strings (recommended), or
  - a raw n8n expression string like `={{ JSON.stringify([...]) }}`.

## Provision New Bots (Interactive)

Use the provisioning script to create/update `deploy/bots/*.json` and configure
the Telegram bot via Bot API after you create the bot in BotFather.

### Manual prerequisites per bot

1. Create bot in [@BotFather](https://t.me/BotFather) with `/newbot`.
2. Copy the `telegram_bot_token`.
3. Create Telegram credential in n8n and copy `telegram_credential_id`.

### Run

From repo root:

```bash
python3 scripts/provision-bots.py interactive
```

Optional flags:

```bash
python3 scripts/provision-bots.py interactive \
  --bots-dir deploy/bots \
  --miniapp-url-base https://learn-language-app.notarobot.dev \
  --overwrite-existing
```

Dry-run mode (no Telegram API calls, no file writes):

```bash
python3 scripts/provision-bots.py interactive --dry-run
```

### What the script configures via Bot API

- `getMe` (token validation + username check)
- `setMyName`
- `setMyDescription`
- `setMyShortDescription`
- `setMyCommands` (`/start`, `/level`, `/voice`, `/stats`, `/feedback`, `/lang`)
- `setChatMenuButton` (mini-app URL with `?bot-key=<base>-<learning>`)
- `setMyProfilePhoto` (optional, if photo path is provided)

### Notes

- Locale content is cloned from a selected template bot JSON (v1 behavior).
- Existing files require overwrite confirmation unless `--overwrite-existing` is passed.
- The script is generate-only: it does not render/import/activate n8n workflows.
